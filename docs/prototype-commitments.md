# الالتزامات الوظيفية

## التزامات تم تنفيذها

- موقع متعدد الصفحات بملفات HTML مستقلة.
- نظام تصميم مشترك عبر `assets/css/site.css` و`assets/js`.
- اعتماد ملف Website Design كمرجع تنفيذي أساسي.
- دعم العربية والإنجليزية فعليًا، مع `lang` و`dir`.
- تنقل علوي إلى: الرئيسية، من نحن، الاستشارات، التنفيذ، القطاعات، قصص النجاح، الرؤى، التواصل.
- `Book a Consultation` كالمسار الأساسي في الرأس والتذييل.
- مسار `Send an Inquiry` مختلف الحقول على صفحة التواصل.
- قائمة هاتف كاملة الشاشة مع قفل التمرير وEscape وإدارة التركيز.
- فهرس استشارات ثابت على سطح المكتب وaccordion على الهاتف.
- عرض الهدف والنطاق والأثر ومؤشرات القياس للحلول التنفيذية.
- عرض القطاعات الستة مع لوحة سياق لوحة المفاتيح.
- عرض قصص النجاح الخمس وصفحات تفصيل `case.html?id=`.
- مكتبة الرؤى مع فلترة تُحفظ في عنوان الصفحة.
- صفحات تفصيل للرؤى `insight.html?id=`.
- نموذج تأهيل مع تحقق فوري و`aria-invalid`.
- عدم مسح النموذج بعد نجاح تجريبي.
- دعم `:focus-visible` و`prefers-reduced-motion`.

## سلوك النموذج

### قبل الإرسال

- يمكن للمستخدم التنقل بين الحقول طبيعيًا.
- الحقول المطلوبة لا تُقفل مسبقًا.
- لا يتم مسح البيانات عند وجود خطأ.

### عند وجود أخطاء

- تظهر رسالة بجانب كل حقل ناقص.
- يتم تحديد الحقل غير الصالح بـ `aria-invalid` و`aria-describedby`.
- يُنقل التركيز إلى أول حقل غير صالح.
- لا تعرض الصفحة رسالة نجاح كاذبة.

### عند النجاح

- تظهر رسالة تأكيد داخل الصفحة (`role="status"`).
- توضح أن الإرسال تجريبي ولا يُرسل إلى خادم.
- لا يُفرغ النموذج حتى لا يُفقد السياق أثناء المراجعة.

## حدود prototype الحالية

- الإرسال محلي داخل المتصفح فقط.
- لا يوجد backend أو API أو CRM.
- لا يوجد تقويم فعلي لحجز موعد.
- لا توجد صور تحريرية معتمدة بعد؛ تُترك مساحة تصوير مع تعليق واضح.
- النتائج والأرقام تحتاج اعتمادًا تجاريًا وقانونيًا قبل النشر.
- الرؤى الحالية نماذج محتوى وليست مقالات منشورة كاملة.

## متطلبات ما قبل الإنتاج

- اعتماد الشعار كملف أصلي SVG/PNG عالي الدقة.
- اعتماد الصور والأسماء والأرقام وقصص النجاح.
- تحديد الدول والأسواق المستهدفة بدقة.
- ربط النموذج بـ CRM أو بريد استقبال.
- تحديد أوقات الحجز الفعلية.
- إضافة سياسة الخصوصية والموافقة على التواصل.
- مراجعة النص العربي والإنجليزي تحريرياً.
- استضافة الخطوط ذاتيًا بدل Google Fonts.
