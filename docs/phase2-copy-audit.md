## Issue Classification Key

- **CLARITY** — Message is unclear, abstract, or could be more specific.
- **SPECIFICITY** — Message lacks concrete detail, numbers, or approved proof linkage.
- **DIFFERENTIATION** — Message does not distinguish Elite Maison from competitors.
- **PROOF** — Message lacks supporting evidence or uses generic claims.
- **VOICE** — Message tone or phrasing is inconsistent with brand voice.
- **CTA** — Call-to-action is weak, generic, or unclear.
- **REPETITION** — Message repeats across sections without adding new value.
- **TRANSLATION** — AR/EN versions do not preserve the same strategic meaning.
- **HIERARCHY** — Message is out of sequence (proof too early/too late, CTA buried).
