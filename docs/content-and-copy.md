# قواعد المحتوى والكتابة

## النبرة

- مؤسسية راقية وهادئة.
- واضحة ومباشرة.
- استشارية وليست دعائية مبالغًا فيها.
- تركّز على التحدي والقرار والنتيجة.
- قصيرة وقابلة للمسح البصري.

## قواعد المصطلحات

- استخدم `Book a Consultation` كالإجراء الرئيسي.
- استخدم `Send an Inquiry` كخيار أولي ثانوي.
- ابدأ بالتحدي، وليس باختيار خدمة مسبق.
- استخدم `Challenge → Strategy → Execution → Result → Proof` لقصص النجاح.
- استخدم `Diagnose → Strategize → Execute → Measure & Improve` لمنهجية النمو.

## العربية والإنجليزية

النسخة العربية والإنجليزية يجب أن تكونا متكافئتين في المعنى، لكن ليس مطلوبًا أن تكون الترجمة حرفية. يجب الحفاظ على:

- نفس الأولوية التجارية.
- نفس الإجراء الرئيسي.
- نفس أسماء الأقسام.
- نفس الأرقام والنتائج بعد اعتمادها.
- اختلاف طبيعي يناسب نبرة كل لغة.

## ممنوعات المحتوى

- عدم اختراع نتائج أو عملاء أو شهادات.
- عدم تحويل Elite Maison إلى وكالة محتوى تقليدية.
- عدم استخدام وعود غير قابلة للقياس.
- عدم جعل الأرقام غير المعتمدة تبدو كضمانات.
- عدم إضافة صفحات أو خدمات خارج Website Content Direction دون اعتماد.
