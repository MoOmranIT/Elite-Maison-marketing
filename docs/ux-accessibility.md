# تجربة الاستخدام والوصول

## المبادئ

- النموذج يستخدم عناصر HTML الدلالية: `header`, `nav`, `main`, `section`, `footer`, `button`, `form`.
- التمييز بين الرابط الذي ينقل المستخدم والزر الذي ينفذ إجراءً.
- إبقاء مكان المستخدم واضحًا عبر `aria-current="page"` في التنقل متعدد الصفحات.
- عدم الاعتماد على اللون وحده لتوضيح الحالة.
- الحفاظ على ترتيب لوحة المفاتيح الطبيعي.

## اللغة والاتجاه

- العربية هي اللغة الابتدائية.
- الإنجليزية متاحة من زر واحد.
- تبديل اللغة يحدّث `lang` و`dir`.
- النصوص والعناوين والأزرار تتبدل مع اللغة.

## لوحة المفاتيح

- كل الروابط والأزرار قابلة للوصول عبر Tab.
- Enter وSpace يعملان على الأزرار الأصلية.
- Escape يغلق قائمة الهاتف.
- `:focus-visible` يستخدم حلقة تركيز واضحة.

## قارئات الشاشة

- يوجد skip link إلى المحتوى.
- كل input له label ظاهر.
- رسائل الخطأ والنجاح داخل live regions.
- حالات الأزرار التفاعلية تستخدم `aria-expanded` أو `aria-selected` حيث يلزم.
- الأيقونات الزخرفية تحمل `aria-hidden`.

## النموذج

- الحقول تستخدم `required`.
- الحقول المنسدلة تستخدم `select` أصليًا.
- لا يعتمد النموذج على placeholder كبديل عن label.
- تظهر الأخطاء بالقرب من الحقول.
- لا يتم تعطيل زر الإرسال كوسيلة وحيدة للتحقق.

## الحركة وأهداف اللمس

- أهداف اللمس مصممة بحد أدنى عملي 44×44px.
- الحركة قصيرة ومرتبطة بفعل واضح.
- يتم تعطيل الحركة تقريبًا عند اختيار `prefers-reduced-motion: reduce`.
- لا توجد حركة وميضية أو auto-play مزعجة.

## حالات يجب الحفاظ عليها عند ربط backend

- تحميل أولي.
- إرسال قيد التنفيذ.
- نجاح الإرسال.
- خطأ قابل لإعادة المحاولة.
- انقطاع اتصال مع الحفاظ على البيانات المدخلة.
- رفض أو خطأ في حقل محدد.
